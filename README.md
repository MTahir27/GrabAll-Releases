## Browser Extensions

All browser extensions are included directly inside the ZenoDM desktop app and automatically extracted into your local App Data folder on launch (**Settings → Browser Extensions**). 

Alternatively, download standalone packaged extension `.zip` archives directly from [GitHub Releases](https://github.com/MTahir27/ZenoDM-Releases/releases/latest):

- **Chrome, Edge, Opera, Brave & Vivaldi** (Manifest V3)
  - Download [ZenoDM-Chrome-Edge-Opera-Extension.zip](https://github.com/MTahir27/ZenoDM-Releases/releases/latest/download/ZenoDM-Chrome-Edge-Opera-Extension.zip)
  - Open `chrome://extensions` (or `edge://extensions`) → enable **Developer mode** → drag & drop or **Load unpacked**.
- **Mozilla Firefox** (WebExtension)
  - Download [ZenoDM-Firefox-Extension.zip](https://github.com/MTahir27/ZenoDM-Releases/releases/latest/download/ZenoDM-Firefox-Extension.zip)
  - Open `about:debugging#/runtime/this-firefox` → click **Load Temporary Add-on…**.
- **Apple Safari (macOS)**
  - Open **Settings → Browser → Safari (Mac)** inside ZenoDM for guided setup.
